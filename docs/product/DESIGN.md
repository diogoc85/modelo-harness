# Diretrizes do Sistema de Design (UI/UX)

## 1. Princípios Visuais
- O sistema deve ser estritamente responsivo e mobile-first.
- Utilize componentes reutilizáveis e evite duplicação de CSS.

## 2. Paleta de Cores e Temas
- **Modo Escuro (Padrão):** Background `#09090b`, Texto `#fafafa`.
- **Modo Claro:** Background `#ffffff`, Texto `#09090b`.

## 3. Componentes e Bibliotecas Autorizadas
- Sempre utilize componentes baseados em `shadcn/ui` e utilitários do `Tailwind CSS`.
- Não instale bibliotecas de UI concorrentes sem autorização explícita do usuário.
